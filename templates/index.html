What I learned

My project, DATA PROBE – Intelligent Dataset Investigation & Anomaly Detection System, investigates unusual patterns, suspicious records, missing values, duplicates, and data inconsistencies.

MY PROJECT TAKEAWAYS

From raw data to useful findings

  • Built practical experience in Python, modular development, NumPy arrays, Pandas DataFrames, preprocessing, data cleaning, missing-value handling, duplicate detection, descriptive statistics, IQR outlier detection, and statistical analysis.
  • Learned unsupervised machine-learning fundamentals, feature selection, Isolation Forest, model training and prediction, contamination settings, and how statistical and ML detectors differ.
  • Practiced evaluation with precision, recall, F1-score, and confusion matrices, and learned about false positives, false negatives, data leakage, and model limitations.
  • Worked with CSV files, interactive dashboards, visualizations, automated reports, debugging, testing, and Git/GitHub version control.
  • Put the complete data workflow together—from raw-data processing and anomaly detection to model comparison, performance evaluation, and reporting.

What this tool can — and can’t — tell you

This project is a way to explore data, not a machine that decides whether a person or record is telling the truth.
